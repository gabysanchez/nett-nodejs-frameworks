# Node.js · Clase 02

Necesitas Node.js 22.16.0 o superior. Desde esta carpeta, ejecuta:

```bash
npm install
npm run dev
```

El puerto se configura con `PORT` en el archivo `.env` de esta carpeta. Con `PORT=3001`, la API está en `http://localhost:3001/events`. Si no se define `PORT`, se usa el puerto 3000.

Para arrancar la versión compilada, ejecuta `npm run build` y después `npm start`.
